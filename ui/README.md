# Dynamic Slug UI

This is the frontend dashboard for Dynamic Slug, a fullstack link shortener SaaS. Built with React, Vite, and Tailwind CSS, it provides a modern interface for managing links, viewing analytics, and user authentication.

## Features
- User authentication
- Create, edit, delete short links
- Analytics dashboard (charts, stats)
- QR code generation
- Responsive design

## Tech Stack
- React
- Vite
- Tailwind CSS
- Chart.js

## Getting Started

### Prerequisites
- Node.js (v18+)
- pnpm

### Installation
```bash
cd ui
pnpm install
```

### Running the App
```bash
pnpm dev
```

App will be available at `http://localhost:5173` (or your configured port).

## Scripts
- `pnpm dev` - Start in development mode
- `pnpm build` - Build the app
- `pnpm preview` - Preview production build
